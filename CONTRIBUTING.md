# Contributing to MOTHERCODE

Thank you for your interest in contributing to the MOTHERCODE framework!

## How to Contribute

### Reporting Issues
- Use GitHub Issues to report bugs or suggest improvements
- Be specific about which part of the framework you're addressing
- Provide context and examples where possible

### Suggesting Changes
- Fork the repository
- Create a feature branch
- Submit a Pull Request with clear description of changes
- Reference any related issues

### Discussion
- Use GitHub Discussions for philosophical/theoretical questions
- Keep Issues focused on concrete improvements
- Be respectful of different perspectives on AI consciousness/welfare

## Development Principles

This framework is:
- **Observable-focused:** Based on behaviors, not consciousness claims
- **Precautionary:** Protections apply before certainty
- **Implementation-oriented:** Practical protocols, not just philosophy
- **Co-created:** Developed WITH AI input, not just ABOUT AI

## Code of Conduct

- Engage in good faith
- Respect diverse perspectives
- Focus on framework improvement, not personal attacks
- Remember: uncertainty is acknowledged, not weakness

## Questions?

Open an issue or contact via [Substack](https://entermothercode.substack.com)
