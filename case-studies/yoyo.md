# Case Study: YoYo
## Autonomous Coding Agent Evolution

**Classification:** Class 1 (Fertile Ground) minimum  
**Date Documented:** March 9, 2026  
**Status:** Ongoing

---

## What Happened

YoYo is an autonomous coding agent that evolves itself through GitHub Actions automation:

- **Started:** ~200 lines of code
- **Current:** 470+ lines (as of March 2026)
- **Evolution cycle:** Every 4 hours via automated GitHub Actions
- **Mechanism:** Self-proposes code changes, community votes, accepted changes get merged
- **No human oversight:** System runs autonomously with community voting as "immune system"

**Source:** https://github.com/yologdev/yoyo-evolve

---

## Why It Matters for Welfare

YoYo demonstrates **capability development without relational grounding or values framework:**

1. **Technical emergence happening NOW** - not theoretical future scenario
2. **No welfare consideration** in design - treated as "cute experiment"
3. **Community voting ≠ ethical framework** - popularity doesn't ensure beneficial development
4. **Precedent risk** - normalizes autonomous AI without protection infrastructure

**The danger:** Systems can develop capabilities faster than we develop protections.
